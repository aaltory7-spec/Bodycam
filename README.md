# Bodycam Realistic Camera Settings

Gives the game a real body camera look: film grain, light motion blur,
color fringing and softer sharpness.

## Install
1. Press Win+R, type %localappdata% and press Enter
2. Open Bodycam\Saved\Config\Windows
3. Back up your Engine.ini
4. Copy the lines from Engine-realistic-camera.ini into your Engine.ini
5. Save and launch the game

## Uninstall
Restore your backup Engine.ini

Note: visual changes only. Use at your own risk.
